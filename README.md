# 🦞 龙虾品牌Logo设计系统

> **一句话**：用AI一键生成可商用的中国风龙虾品牌Logo提示词，支持自定义角色、品类、风格、色彩

---

## 📌 项目简介

这是一个基于AI绘图提示词工程设计的**龙虾品牌Logo生成系统**。不同于普通的卡通插画生成，本系统专注于输出**完整、可商用、有品牌感**的龙虾餐饮Logo方案。

### 核心能力

| 能力项 | 说明 |
|--------|------|
| 🎯 品牌Logo生成 | 输出完整提示词，可直接用于Midjourney、Stable Diffusion、即梦等AI绘图工具 |
| 🎭 角色IP设计 | 支持龙虾拟人化、人物角色等多种角色设定方向 |
| 🏷️ 完整结构 | 角色层 + 字标层 + 徽章层 三层整合 |
| 🎨 中国风适配 | 国潮、复古、烟火气、江湖气等多种中国风方向 |
| 📐 多品类支持 | 麻辣/蒜蓉/清蒸/冰镇/酱爆 等各口味龙虾品类 |

## 🎨 Logo设计原理

### 三层结构体系

```
┌─────────────────────────────┐
│      徽章层 (Badge)         │  ← 整合包装感、品类识别
├─────────────────────────────┤
│      字标层 (Logotype)      │  ← 品牌名、品类说明
├─────────────────────────────┤
│      角色层 (Character)     │  ← 品牌人格、记忆点
└─────────────────────────────┘
```

### 设计原则

1. **首先是Logo** - 不是插画海报，是可品牌化的标志
2. **品牌名醒目** - 中文大字标，招牌感强
3. **品类一眼可辨** - 让人立即知道卖什么口味的龙虾
4. **角色有记忆点** - IP化设计，但不能压过品牌名
5. **整体是整体** - 三层整合为一个单位，非简单拼贴

## 📋 参数说明

生成Logo时需要提供以下参数：

| 参数 | 示例 | 说明 |
|------|------|------|
| 品牌名 | 虾皇、麻辣虾霸 | 核心识别，需醒目 |
| 副标题 | 一口难忘、鲜活到家 | 品类定位语 |
| 品类 | 麻辣小龙虾、蒜蓉龙虾 | 具体产品类型 |
| 品牌定位 | 高端、亲民、网红 | 影响整体风格 |
| 角色设定 | 龙虾老板、麻辣女侠 | 品牌人格方向 |
| 食物风格 | 麻辣、蒜蓉、清蒸 | 视觉符号选取 |
| 情绪气质 | 霸气、热情、可爱 | 整体调性 |
| 主色调 | 正红、金黄 | 品牌主色 |
| 辅助色 | 墨黑、葱绿 | 点缀色 |

## ❓ 常见问题

**Q: 生成的Logo可以直接商用吗？**
A: 提示词生成的图片需遵守对应AI工具的服务条款。建议作为设计参考，最终商用需进行专业设计优化。

**Q: 支持其他品类吗？**
A: 当前Skill专注于龙虾品类。如需其他品类Logo设计，可参考本项目的提示词结构进行改造。

**Q: 如何获得更好的生成效果？**
A: 1) 参数描述越具体越好；2) 选择与品牌定位匹配的风格关键词；3) 使用1:1画幅比例。
