## 🎯 提交作品

如果你使用本项目生成了Logo作品，欢迎提交到本目录！

### 提交方式

1. Fork 本仓库
2. 将作品图片放入 `works/images/` 目录
3. 在下方「作品列表」中添加条目
4. 提交 Pull Request

### 命名规范

```
{品牌名}-{品类}-{日期}.png
示例：虾皇-麻辣小龙虾-20260513.png
```

### 推荐尺寸

- **主图**: 1024x1024 (1:1 方形)
- **缩略图**: 512x512
- **封面展示**: 1920x1080 (可选)
